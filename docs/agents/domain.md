# 领域文档

工程 skill 探索代码库时，按以下规则读取领域文档。

## 探索前读取

- 根目录的 `CONTEXT.md`；如果存在 `CONTEXT-MAP.md`，则读取它指向的相关上下文文档。
- `docs/adr/` 中与当前工作区域相关的 ADR。
- 没有这些文件时静默继续，不提前要求创建。

## 单上下文布局

本仓库采用单上下文布局：

- `CONTEXT.md`：领域术语和边界
- `docs/adr/`：架构决策记录
- `src/`：实现代码

## 使用术语表

issue 标题、重构方案、假设和测试名称中的领域概念，应使用 `CONTEXT.md` 定义的术语。不要使用术语表明确避免的同义词。发现术语缺口时，记录为领域建模问题。

## 处理 ADR 冲突

如果输出与现有 ADR 冲突，应明确指出冲突的 ADR 编号和原因，不要静默覆盖。
