# P3.1 创建与会话交付记录

状态：进行中。

已实现 Coordinator 的会话注册表与关闭仲裁。注册验证非零身份，拒绝重复活跃身份和超过配置的活跃会话数。leave 将会话设为不活跃，保留 last_accepted；同身份再次注册不会重置序号。该运行期重新登记不提供检查点恢复保证，continue_session 仍属于 P5。

accept_serial 在同一注册表锁内验证会话活跃、存储未关闭及序号严格递增；跳号合法，拒绝不修改原进度。后续引擎必须先完成其他接收条件检查，再调用此入口，不应在仍可能拒绝的准备路径提前消费序号。

shutdown 在同一锁内检查活跃会话；仍有会话立即返回 Busy，不等待本线程。成功后不可再注册，重复 shutdown 幂等成功。注册与关闭采用同一线性化点，不存在两者同时成功却仍返回活跃会话的状态。

测试覆盖重复注册、容量、关闭失败不关闭存储、独立会话序号、跳号/回退、重新登记保持进度、真实线程注册/关闭竞争。注册表保留已出现身份的进度，后续检查点与资源验收须明确其持久化和保留成本，不能静默丢弃恢复信息。

当前尚未接通 Builder::create、公开 Session 的注册与 close、设备关闭及引擎初始化；不能宣称已创建可用 RasterKV。下一步完成这些真实入口，CRUD 仍由 P3.2/P3.3 接入。

本轮本地 Rust 1.98.1 格式、Clippy、全特性测试及 rustdoc 通过，共 75 个运行测试、6 个文档测试。仅为注册状态机子步骤验证，P3.1 整体尚未完成。
