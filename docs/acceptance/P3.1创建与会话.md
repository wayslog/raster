# P3.1 创建与会话交付记录

状态：完成。

已实现 Coordinator 的会话注册表与关闭仲裁。注册验证非零身份，拒绝重复活跃身份和超过配置的活跃会话数。leave 将会话设为不活跃，保留 last_accepted；同身份再次注册不会重置序号。该运行期重新登记不提供检查点恢复保证，continue_session 仍属于 P5。

accept_serial 在同一注册表锁内验证会话活跃、存储未关闭及序号严格递增；跳号合法，拒绝不修改原进度。后续引擎必须先完成其他接收条件检查，再调用此入口，不应在仍可能拒绝的准备路径提前消费序号。

shutdown 在同一锁内检查活跃会话；仍有会话立即返回 Busy，不等待本线程。成功后不可再注册，重复 shutdown 幂等成功。注册与关闭采用同一线性化点，不存在两者同时成功却仍返回活跃会话的状态。

测试覆盖重复注册、容量、关闭失败不关闭存储、独立会话序号、跳号/回退、重新登记保持进度、真实线程注册/关闭竞争。注册表保留已出现身份的进度，后续检查点与资源验收须明确其持久化和保留成本，不能静默丢弃恢复信息。

当前尚未接通 Builder::create、公开 Session 的注册与 close、设备关闭及引擎初始化；不能宣称已创建可用 RasterKV。下一步完成这些真实入口，CRUD 仍由 P3.2/P3.3 接入。

本轮本地 Rust 1.98.1 格式、Clippy、全特性测试及 rustdoc 通过，共 75 个运行测试、6 个文档测试。仅为注册状态机子步骤验证，P3.1 整体尚未完成。


## 公开生命周期接入

Builder::create 先验证配置，初始化 store 身份、共享 schema、索引、页池、epoch 和协调器，再调用实际 DeviceFactory::open；成功后才返回 RasterKV。缓存、自动压缩和预分配尚未接入时明确拒绝相应配置。设备打开失败直接返回原错误；恢复仍明确拒绝且不打开设备。

NullDeviceFactory 为受限内存路径提供无 I/O 设备，所有提交原样拒绝且不承诺恢复；poll 没有完成项，shutdown 无在途资源可排空。这是 P3 创建所需的最小真实后端，P4 仍须完成统一设备与故障协议验收。

start_session 登记协调器与 epoch，分配本线程 SessionRuntime；close 注销空会话且可重复调用，Drop 注销尚未显式关闭的空会话。shutdown 在活跃会话存在时立即 Busy，成功停止注册后再调用设备关闭；设备超时可重试，但不会重新开放注册，排空完成后重复关闭不再调用设备。Pending 排空仍待 P4，当前四操作全部拒绝，不能产生在途请求。

新增五项公开接口测试覆盖创建/克隆/注册/关闭、重复身份与容量、跨线程共享实例、Drop 注销、设备关闭失败与重试。原骨架边界测试更新为创建真实调用工厂并传递失败，恢复依旧不调用工厂。本地总数 80 个运行测试、6 个文档测试；原生 CI 待核验，P3.1 暂列待验收。CRUD 与可执行业务示例继续在 P3.2/P3.3 实现。
