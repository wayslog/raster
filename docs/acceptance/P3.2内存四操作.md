# P3.2 内存四操作交付记录

状态：进行中，Read/Upsert 已接通，RMW/Delete 尚待实现。

SessionRuntime 携带会话身份，接受时通过协调器校验单调序号并同步本地进度。操作接受前获取哈希分组仲裁，竞争返回 Rejected::Busy，保留请求且不消费序号；接受后返回一次 Ready 结果。

Read 从索引链头按完整键编码查找，缺失返回 NotFound，存在时在页许可下执行用户读回调。Upsert 优先执行原地更新，Append 时构造新值，完成日志初始化后条件发布索引。相同哈希的原地更新与替换共用整个操作区间的仲裁，不仅依赖索引 CAS。

普通错误在尚未修改时返回 NotApplied；进入可能修改旧值的用户函数后错误标为 Unknown 并失败关闭，不自动重试。Updated 成功及索引发布后记为 Applied。捕获业务回调恐慌并失败关闭；回调之外的 codec/请求析构恐慌、完整错误分类和历史验证继续由 P3.3 审计。

公开接口测试覆盖空库 NotFound、首次插入、原地更新、Append 替换、序号拒绝不改变值、同 tag 不同键读取，以及修改后错误不重跑并使后续操作拒绝。本地 Rust 1.98.1 的格式、Clippy、全特性测试及 rustdoc 通过，共 83 个运行测试、6 个文档测试。

仍待完成：RMW 的条件创建/复制更新、Delete 墓碑与选项、普通/变长值公开业务、同键多线程及参考模型交叉验证。读取墓碑选项随 Delete 接入；当前不产生墓碑。没有磁盘 Pending、检查点或恢复能力。
