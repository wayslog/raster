# P8.1 TOML 依赖审计

新增直接依赖固定为 `toml = "=1.1.6"`，锁定发行包 `1.1.6+spec-1.1.0`。它仅由 `config-toml` 特性启用，关闭默认特性，只启用 `std` 和 `parse`，通过 `DeTable` 完整解析语法，再由本项目严格映射字段。没有开启 serde、display、preserve_order 或 unbounded；未引入全局日志库。cap-std 及原有锁定版本不变。

依据为本次下载的发行包 Cargo.toml、Cargo.lock、`cargo metadata --locked --format-version 1 --all-features` 及 `cargo tree --locked --all-features --edges normal`。官方入口：[toml 发行包](https://crates.io/crates/toml/1.1.6+spec-1.1.0)、[源仓库](https://github.com/toml-rs/toml)。声明 MSRV 只是发行包元数据，实际项目兼容性由 Rust 1.98.1 构建和双平台矩阵确认。

本次锁文件新增 15 个发行包，总共 54 个外部发行包（包括平台条件包）。`cargo metadata` 展示的解析闭包包含未在当前构建中编译的条件依赖，不能把它直接当作实际构建图。当前 Linux/macOS 的 `config-toml` 正常构建新增 5 个包：toml、serde_spanned、toml_datetime、toml_parser、winnow；默认特性不增加 TOML 包。所有发行包 checksum 固定在 Cargo.lock，实际编译图由 Cargo tree 记录；未因审计开启更多上游特性。

新引入项声明 MSRV 均不高于 1.85.0，没有超出项目 1.98.1。许可证保留各发行包条款；`unicode-ident` 另含 Unicode-3.0，但属于本次未编译的条件闭包，仍明确列出，不省略许可证审计。本文不重新许可依赖，也不将锁定 Windows 条件包解释为支持 Windows 后端。

原始本地审计位于 `target/p8-dependency-audit.json`、`target/p8-dependency-tree.txt`；长期记录采用本表及提交中的 Cargo.lock，避免归档包含本机目录的原始 metadata。编译、测试和原生 CI 的最终证据统一见 [P8.1 交付记录](P8.1配置诊断交付记录.md)。
