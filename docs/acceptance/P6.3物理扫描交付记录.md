# P6.3 物理扫描交付记录

状态：**P6.3 已完成。2026-09-11，公开扫描与全部缓冲模式通过本地及 Linux/macOS 六组交付检查。**

## 公开行为与范围

`RasterKV::scan(ScanOptions)`、`RecordScanner::next_record` 和 `close` 已实现。扫描固定半开地址范围，按物理地址返回拥有型结果；不按键去重，也不提供全局一致快照。可使用 Full 检查点报告的 begin/end 扫描其覆盖范围，恢复后同样可用。

开放前拒绝无效地址、倒置、超过 tail 及非空范围的半记录边界。驻留边界在日志控制锁中检查，冷页非对齐边界通过完整页读取验证后才返回扫描器。空范围允许位于记录内部，返回结束。尚有未发布预留时保守拒绝或等待，避免越过迟到记录。

旧版本、墓碑和 invalid 记录均按物理顺序保留。键必须能由 Schema 规范解码；普通记录返回拥有型值，墓碑和 invalid 的值为 `None`，不调用值解码器。无法解码的 invalid 键明确报错。零间隙与页末填充不生成记录。RPAG 帧的页号、长度、整体校验及全部记录都须正确，范围外损坏也不能绕过校验。

读取过程中 head 前移会转向磁盘；逻辑 begin 越过尚未消费的位置则返回 `RangeTruncated`，不能解释为正常结束。返回记录前再次检查逻辑边界，覆盖拥有值解码期间发生的截断。Busy、DeadlineExceeded、OutOfMemory 不消费尚未交付的记录，可以重试；其他错误终结扫描。专家键值解码或执行恐慌会失败关闭引擎，不自动重新执行。

## 内存访问与拥有输出

ValueLayout 的必需方法 `decode_owned` 将稳定编码转换为独立 Owned 值，其语义须与 decode_initialize/read 一致。AtomicU64Value、SerializedValue 和 SharedValue 已实现，外部专家布局也须提供该方法。磁盘 FormatId 和冻结的 v1 编码不变。

驻留记录通过 `PageValue::snapshot_record` 的独占许可复制，排除普通和原子更新，不为扫描永久冻结记录或推进只读边界。`HybridLog::snapshot_next` 只短期持有一条记录的 Arc，编码时释放日志控制锁，返回前释放记录引用。输出不依赖输入、游标、存储或后续原地更新。

磁盘 `PageCursor` 持有完整帧和槽位索引；读取完成后由 `ReadPage::into_scan` 转交，按需解码用户值。所有模式都可在扫描期间继续写入并淘汰原驻留页，后续扫描转向磁盘且保持原固定 end。

## 预读与预算

固定上游提交 `321d872eabda6a0345c8bd76419f89723ed864ae` 的 [log_scan.h](https://github.com/microsoft/FASTER/blob/321d872eabda6a0345c8bd76419f89723ed864ae/cc/src/core/log_scan.h#L741) 将模式定义为额外预读页数。当前实现对应如下：

| 模式 | 当前页外预读 | 最大逻辑页槽 |
| --- | --- | --- |
| Unbuffered | 无 | 1 |
| SinglePage | 下一页 | 2 |
| DoublePage | 后续两页 | 3 |

只预读固定范围内已经进入磁盘区的页，不为扫描预先冻结可变页。每个页槽最多一个在途请求，跨段和短读会继续提交余下字节。当前页之外的结果可以提前完成，但不执行用户解码或回调。

`Config.scan.max_scanners` 默认 16，`timeout` 默认 30 秒，用于 scan 的边界读取、next_record 等待和 close；二者须非零。完成邮箱容量为会话 Pending 预算、两个维护路由及每扫描最多三个读取路由之和，所有算术检查溢出。页槽数不是精确进程内存字节数：分段传输的汇总字节、设备拥有缓冲及校验索引另有有界开销，仍受页尺寸和设备队列限制。

## 生命周期、路由与物理租约

扫描独立注册，不冒充会话或加入检查点的会话屏障。注册与 shutdown 共用关闭锁；活跃扫描使 shutdown 返回 Busy。扫描在达到 EOF 后注销，重复 next_record 仍返回 None；显式 close 幂等，已关闭扫描不能重新读取。

设备完成经过共享 CompletionHub，扫描只取自己的邮箱，其他会话的完成保留到原会话处理。会话、维护及扫描轮询都可推进已有扫描窗口的字节读取，不执行扫描的用户解码，不扩张预读窗口。

close/Drop 停止补发读取，但保留已接受请求的页状态、完成路由和扫描名额，直到完成归还。close 超时后可再次关闭；Drop 使用独立原子标志，收尾线程暂时持锁也不会丢通知。引擎注册表只持有扫描状态，不反向持有引擎，避免引用环。设备确认 shutdown 排空后才释放异常收尾中的剩余槽。

扫描页读取通过 `SegmentedStorage::lease_read` 在段映射锁内取得短期租约，`invalidate` 在租约存续期间返回 Busy。租约覆盖完整页帧可能跨越的各段，并持续到已接受 I/O 归还；关闭或 Drop 不能提前解除。在页成为拥有副本后立即释放租约，活跃扫描本身不长期 pin 对应段。扫描闲置时，其他会话轮询也能完成分段预读并释放租约。
