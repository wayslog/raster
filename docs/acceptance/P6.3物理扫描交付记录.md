# P6.3 物理扫描交付记录

状态：**进行中**。已实现拥有型值解码、驻留记录的短期扫描副本、磁盘页游标及原生页读取验证；公共 scan/next_record、三种缓冲及扫描关闭尚未接通，不能宣称物理扫描已可用。

## 拥有型值接口

ValueLayout 新增必需方法 decode_owned，将稳定编码转换为独立的 Owned 值，不借用输入、日志页或活跃槽，语义须与 decode_initialize/read 一致。该方法补足 ScannedRecord 返回拥有值所需能力；不以 Read 视图可 Clone 或内存复制假设替代专家布局协议。

内建 AtomicU64Value 和 SerializedValue 分别使用已有整数与 ValueCodec 解码，SharedValue 原样转发，测试布局也已补齐。开发期外部 ValueLayout 实现须实现该新增方法；磁盘 FormatId 与 v1 编码不变。测试核对整数边界、非法长度、空/非 UTF-8/变长字节，以及拥有解码与活跃槽解码的一致性和输入销毁后的独立性。

## 驻留记录扫描副本

PageValue::snapshot_record 在记录独占许可内编码，排除普通与原子更新，不要求记录已经 sealed，也不改变 sealed、只读边界或尾部。原 encode_record 刷盘入口仍要求已冻结记录和版本上界；二者共用编码实现，扫描不能放宽刷盘契约。

HybridLog::snapshot_next 在短期边界/记录表锁下选取地址递增的下一条已初始化驻留记录，复制 Arc 后释放控制锁，调用专家布局编码，然后释放记录引用并返回拥有型字节。不跨调用持有页引用，也不复制整个日志。后续原地更新不改变已经返回的副本。

非空扫描的起止地址不得落在已知记录中间，范围不得倒置或超过 tail。放弃槽与对齐空隙可以跳过，空范围返回结束。尚有未发布预留时保守返回 Busy，避免跨过后来才出现的记录；记录正在更新同样返回 Busy，不推进调用者游标。该层遇到 head 之前范围返回 RangeTruncated，未来扫描驱动须区分逻辑 begin 失效与 head 前移造成的磁盘重定位。

## 磁盘页游标与拥有型输出

`scan::page::PageCursor` 消费一个完整 RPAG 帧，校验页号、长度、整体校验和及全部记录，再保存拥有型帧和请求范围内的槽位索引。输入范围是当前页内的半开区间；非空区间的边界不得切断记录，零填充不生成记录。空区间可以位于槽位中间，但仍须通过整个输入页校验。范围外损坏也会拒绝，不能借助范围裁剪隐藏损坏。

游标按物理地址返回所有选中的记录，不按键去重，不过滤旧版本、墓碑或 invalid 标志。返回规范解码的拥有型键；普通记录返回拥有型值，墓碑和 invalid 记录返回 `None`，不会调用值解码器。invalid 记录的键如果不能由当前 Schema 规范解码则报错，不虚构键或静默跳过。键值解码恐慌转为错误，后续公开扫描驱动仍需接入失败关闭；内部解码失败不推进页游标。

`ReadPage::into_scan` 将通过设备读取和分段绑定检查的拥有型页转交游标。输出可以在页游标及存储销毁后继续使用；游标不持有设备缓冲借用，也不持有活跃日志页引用。当前仍未实现扫描器注册、整段范围驱动、预读或 Drop 协议。

新增八项内部测试覆盖独立冻结样例、逐字节损坏/截断、错误页号与尺寸、半记录边界、填充、同键旧版本、墓碑/invalid、变长/空/非 UTF-8 数据、整数边界、解码失败不推进，以及解码恐慌。新增一项原生设备贯通测试写入 400 条记录并完成 Full 检查点，经共享完成路由读取全部磁盘页，验证物理顺序和拥有输出，并确认扫描轮询不会执行另一个 Pending 用户读取的回调；该读取仍由原会话正确完成。这是内部读取链路证据，不能代替公共扫描器及三种缓冲模式验收。
