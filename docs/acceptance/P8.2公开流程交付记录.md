## 交付范围

[公开接口使用流程](../16-公开接口使用流程.md) 给出五个可运行示例、目录使用规则、完整磁盘流程、等待和错误语义，并将 A01—A28 对应到实际 API 与测试。A28 明确保留为 P9 总验收任务。新增代码不引入依赖、不改变 v1 持久化格式、不开放后置后端。

- `interface` 替换旧骨架展示：真实多 Pending、异构输出、Rc 上下文、跳号和拒绝、已过期截止时间、会话关闭后取结果、重复收取拒绝。
- `disk_lifecycle`：16 KiB 日志写入 40 个键的两代变长值与墓碑，实际冷读及缓存命中、扩容、三种扫描模式、三种检查点、配对恢复和完整恢复、两种压缩、GC 与依赖顺序释放、诊断统计、关闭。
- `automatic`：800 次写入与自动压缩交错，等待真实压缩完成后停止、检查 32 个最新值、提交检查点并关闭。一次本地运行完成 7 次压缩；次数取决于调度，不作为固定预期。
- `memory` 与 `memory_matrix` 保留已有工作负载，错误传播保留完整 OperationError，Busy 重试有界。所有示例只调用公开入口。
- crate 首页、Config 子表解析及 OperationError 新增可执行 rustdoc 示例；补充注册、续接、检查点、压缩、等待、关闭与诊断的公开契约。
- CI 在原有检查后实际运行五个示例及 `scripts/check_examples.py`，后者验证已有目录拒绝、参数错误不创建、显式目录保留、二次运行材料不变。

## 核对功能表时修复的缺口

早期 A07 规定每线程每存储至多一个活跃会话，但注册入口未执行该限制。P8.2 增加每实例线程名额及拥有型租约，覆盖创建、恢复续接、准备失败、显式关闭和 Drop；不使用全局 TLS，不添加 unsafe。克隆存储共享名额，同线程不同实例独立，不同线程可各有会话。关闭后不必销毁对象即可重新注册。

新增测试核验重复拒绝、容量、跨实例/跨线程隔离、准备失败不占名额、恢复身份关闭重续且 last_accepted 不退回检查点。15 个原组件测试及多会话轨迹原先在一个线程模拟多个 Session，现用真实工作线程及同步指令控制原交错；Session、Rc、请求与 Ticket 只在所属线程创建和保留，未绕过注册检查。未删除、忽略原场景或放宽数据结果断言。

恢复会话原来就允许关闭后重续，文档现明确区分检查点 progress 与本实例最新接受序号。关闭继续使用统一 Error::Busy；`Diagnostics.active_session_ids` 补充实际活跃身份，和 active_sessions 从同一次注册表读取得到，避免泛化 Busy 后无法定位会话。没有引入旧接口草案中的专用 ShutdownError。

OperationError 实现 Display 和标准 Error，source 保留 cause，输出明确生效范围。维护报告保留共享的原始 Result；流程和收尾同时失败时输出两个错误。自动示例最初把未接受 Busy 直接作为终止，实际运行暴露了与压缩争用的背压；修正为仅重试归还的未接受请求及其原序号，已接受票据仍只推进、不重放。
