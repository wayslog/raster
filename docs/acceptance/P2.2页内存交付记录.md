# P2.2 页内存与许可交付记录

状态：完成。

已实现 `log/gate.rs` 的 MutationGate：一个顺序一致的原子状态字维护共享原子更新计数，保留全一值表示替换独占。try_update/try_replace 单次尝试，竞争返回 Busy，不隐藏无限自旋。共享许可退出递减计数，独占许可退出清零；许可借用 gate 且不可跨线程移动。

普通值访问不能使用共享原子更新许可；普通读写和替换须取得独占许可，防止普通字节访问与更新混用。此处的许可仅证明仲裁，不证明记录已初始化、页存活、代次正确或允许当前检查点版本修改；页池和引擎接入时必须一起满足这些条件。

定向测试覆盖共享互容/独占互斥、真实线程交错、计数上限、恐慌展开和遗忘许可。恐慌释放 gate 不代表操作可重试；错误影响和引擎失败关闭必须由 P3 负责。

尚未交付：页池与记录生命周期整合、预留/发布/放弃、初始化失败清理、记录租约、内建 ValueLayout、Miri 验收。P2.2 保持进行中，不以仲裁单元测试代替这些要求。

## 页范围所有权子步骤

新增 `log/page.rs`：页池按二次幂页大小分配零初始化内存，控制锁只负责分配不重叠范围。PageRange 不可克隆，拥有页的 Arc 引用，独占可变借用才能访问该范围；移动不改变地址，池销毁也不会释放仍有范围引用的分配。整页释放要求没有范围引用，复用时分配新逻辑页号并递增物理槽代次；旧身份无法释放新页。

页预算耗尽、长度/对齐非法、地址或代次不可表示时拒绝，不覆盖活跃内存。遗忘范围会阻碍释放，不使其他范围悬垂。当前尚无 I/O 引用或恢复集引用，后续调用 release 前必须完成逻辑退役、epoch 和外部保留检查；Arc 引用数只证明分配存活，不代替这些业务约束。

新增裸分配的安全不变量：Layout 非零且合法；分配与释放使用同一 Layout；每个范围严格在页内且互不重叠；页本身不创建覆盖所有范围的引用；最后一个 Arc 退出才释放。PageRange 的裸指针不授予安全解引用权，后续专家布局访问仍受记录许可约束。

## 页内值布局子步骤

`log/value.rs` 的 PageValue 持有真实 PageRange 和共享布局，只在初始化成功后返回对象。读取和稳定编码持独占 gate；普通更新同样独占，明确声明 concurrent_updates 的原子布局允许共享更新。高阶闭包约束视图寿命，视图不能借由返回值逃出许可作用域。最后所有者调用 drop_value；销毁错误或恐慌时保留范围，避免不确定清理后的悬垂访问。更新恐慌将该值置为失败关闭，但完整引擎错误影响仍待 P3 接入。

SerializedValue 现在实现 ValueLayout，活跃槽包含八字节长度前缀和编码字节，因此 live 大小为 encoded + 8，对齐为 8。此前 P1.3 的槽外长度草图据实际访问接口作此调整；前缀不进入磁盘格式，codec FormatId 和稳定编码保持不变。替换先在临时 Vec 编码，再检查完整槽容量，失败不修改槽。

AtomicU64Value 真实初始化对齐的 AtomicU64 对象，读取/更新/稳定编码都使用原子数值操作，禁止把原子对象当普通字节复制。布局的 concurrent_updates 默认 false；专家实现返回 true 时必须证明多个 Update 视图可安全并存。

新增四项测试：普通值缩短及增长拒绝、四线程原子增量与恢复初始化、更新恐慌失败关闭、损坏解码不返回值且范围可释放。Rust 1.98.1 的格式、Clippy、全特性测试、rustdoc 通过，共 60 个运行测试、5 个文档测试。

`cargo +nightly miri test --locked --lib log::value` 四项通过，保持默认泄漏检测。使用与前一节相同的 nightly/Miri 版本。上轮页池提交 `9973fd8` 原生 CI 34456582818 已确认成功。

## 记录发布与租约接入

HybridLog 现在按 ValueLayout 泛型持有页池和地址表，Engine 使用 `HybridLog<S::Value>`。reserve 完成初始化后返回未发布预留；只有 finish_initialization 将记录放入地址表，abandon 或直接丢弃预留均销毁值而不发布。跨日志预留明确拒绝。地址表只保存已经初始化的拥有者，不暴露半记录。

租约拥有 Arc 记录引用并绑定当前线程；页代次匹配入口拒绝错误代次。retire 先在独占 gate 下停止更新，再移出地址表；旧租约仍可读，但不能继续修改。最后租约退出才销毁值，因此 epoch 之外还有真实所有权保护，不依赖裸地址保活。上层仍须先摘除索引可见性，页物理释放还须满足 I/O/恢复集合约束。

当前页内预留只包含值槽，键/前驱/版本的完整记录装配由 P3 接入，磁盘页循环和刷盘仍由 P4 实现。已有值地址不会被静默复用。本阶段不声明混合日志磁盘能力。

新增四项真实日志接口测试：未发布不可见与放弃、退役后旧租约保活、跨日志拒绝和日志销毁后租约存活、专家布局部分初始化失败清理及成功值恰好销毁一次。另新增原子 UpdatePermit 生命周期 compile_fail 文档测试。
