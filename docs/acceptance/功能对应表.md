## 已有证据与后续边界

- 已有骨架：配置、ValuePlan、对齐缓冲四个 foundation 测试；两个 skeleton_boundary 测试；三个结果槽单元测试；五个 compile_fail doctest。
- P0 工具：p0_reference 中九个测试验证固定轨迹、生成/往返、损坏输入、序号、多会话、变长/类型错误、故障、生命周期和模拟恐慌，详见验收报告。
- 所有 A01—A28 引擎场景均未验收；原子并发、I/O、恢复、扫描等必须到负责任务跑真实接口。
- 可选完成观察器尚无公开入口，归 P3.3/P4.4；计算允许重试，观察器终结后调用、panic 不重放操作。上游 I/O 错误回调线程差异改为 Rust 原会话线程。
