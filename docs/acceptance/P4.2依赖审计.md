# P4.2 文件后端依赖审计

直接依赖固定为 cap-std =4.0.3，默认特性为空。采用目录句柄相对操作限制子路径访问，不依赖先 canonicalize 再打开的字符串检查。依据 [Dir 官方文档](https://docs.rs/cap-std/4.0.3/cap_std/fs/struct.Dir.html) 与 [发行包清单](https://docs.rs/crate/cap-std/4.0.3/source/Cargo.toml)。

审计使用本次 Cargo.lock 与 cargo metadata --locked。cap-std 没有声明 rust-version，不虚构其 MSRV；已在项目 Rust 1.98.1 实际编译与本地文件测试通过，Linux 原生闭包由 CI 继续确认。所有引入项都提供许可证表达式；保留各发行包许可证，不在此重新许可。未启用网络 API，本项目只使用 fs。
