# P3 内存性能基线

这是优化前的首轮数据，不是生产性能承诺。命令：`cargo run --locked --release --example memory_matrix`。配置为默认内存参数、Null 后端、release、Rust 1.98.1；Apple M1 Pro，macOS 26.5.2，aarch64-apple-darwin。没有文件 I/O，因此本轮文件系统不参与路径。

每组 20000 次 Upsert，3 次独立创建的重复运行；原子 u64 与 32—512 字节普通值，256 键确定均匀访问和单键热点，1/4 线程。各次成功返回值验证等于该次输入标识，错误直接失败。延迟包含接受前 Busy 重试，重试不重复接受。吞吐计时含屏障等待、首次页分配、工作循环及会话关闭；逐次延迟不含请求构造。无预热，短样本受调度影响明显。

后续比较规则在优化前固定：仅同机器、同工具链、同输入与计时方式比较；三组重复中位数若吞吐下降超过 25% 或 P99 上升超过 30%，启动复核，追加更长样本并检查调度/资源因素，解释或修复后再验收。短样本异常不直接证明代码退化，也不能删除不利样本规避问题。正式 P9 会扩展时间长度、读写比例、I/O 放大、内存和恢复耗时；本轮不能替代那些门槛。
