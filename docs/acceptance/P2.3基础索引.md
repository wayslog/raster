# P2.3 基础索引交付记录

状态：进行中。

MemIndex 按配置创建二次幂数量的桶，每桶独立 Mutex；七槽块满后追加溢出块。桶由哈希低位定位，tag 取高 16 位。相同桶/tag 共用链头，索引不保存键和值，也不把 tag 相等当成键相等。

prepare 返回包含管理器身份、桶、tag、链头、表代次和修订号的快照，包括空链头。compare_publish 在桶锁内比较全部快照字段后更新，实现线性化条件发布；失败返回当前快照供重查。每次成功递增修订号，清空链头仍保留修订号，防止地址经过删除再回到原值时旧快照误成功。身份、表代次、地址或计数溢出均明确拒绝。

快照按桶采集，是模糊映像，不是跨桶事务快照；缓存头在规范化前拒绝进入映像。restore 留到 P5，在线扩容留到 P6。锁内不调用用户函数，不持有值对象；后续扩大表仍须更新代次并保护旧表。

六项测试覆盖溢出块、不同 tag、相同桶/tag、地址 ABA、跨索引及表代次拒绝、缓存映像拒绝、两个线程竞争一个快照，以及使用真实 HybridLog 的初始化后发布与失败发布清理。失败索引发布不会自动销毁日志记录，由拥有者调用 retire；未初始化预留在日志地址表不可见。

本地 Rust 1.98.1 格式、Clippy、全特性测试和 rustdoc 通过，共 70 个运行测试、6 个文档测试。仍待补完整编码键的日志链查找与碰撞验证，再完成原生六组合验收；当前同 tag 测试只证明它们共用链头，不作为完整“不串键”证据。
