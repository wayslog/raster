## 回调阶段矩阵

新增 11 个阶段组合，分别在 Read、Upsert replacement、RMW initial、copy_update、原地 Update 注入普通错误或恐慌，另在 Delete complete 注入恐慌（该接口没有错误返回值）。每项核对接受序号、Effect、故障命中次数恰好一次，以及失败后是否允许继续业务。

| 阶段 | 普通错误 | 恐慌 |
| --- | --- | --- |
| Read / replacement / initial / copy_update | NotApplied，后续读取验证旧状态未改变 | NotApplied，引擎失败关闭 |
| 可能修改的 Update | Unknown，失败关闭，不重试 | Unknown，失败关闭，不重试 |
| Delete complete | 接口不返回 Result | Applied，失败关闭，不重复完成 |

与已有请求键恐慌、请求析构恐慌、重复序号拒绝测试共同覆盖接收边界和终结边界。另通过真实 ReadOperation 返回 Rc<String>，检查与用户原输出 Rc::ptr_eq，验证非 Send 上下文与输出没有被移交设备线程。
