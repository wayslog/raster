## 有界并发历史与公开示例

`tests/p3_history.rs` 记录每次实际被接受的调用起止序号、四操作输入与结果。接受前 Busy 的重试单独检查不消费序号；成功调用的历史检查枚举保持实时先后关系的合法顺序，逐步匹配值与删除/缺失结果。32 轮、每轮三会话九次混合操作全部可线性化，覆盖原地与追加更新、读取和删除。检查器自身用合法重叠、伪造返回值和实时顺序违例验证。这是小规模有界历史证据，不声称证明任意规模交错。

`examples/memory.rs` 仅使用公开 API，实际运行创建、10000 次计数器 RMW、读取校验、删除、Session close 与 store shutdown。命令：`cargo run --locked --release --example memory`。

首轮单线程热点微基线：Apple M1 Pro，macOS 26.5.2，aarch64-apple-darwin，Rust 1.98.1 release，默认特性、Null 后端，10000 次 RMW；2257464 操作/秒，P50=84ns，P95=125ns，P99=208ns。吞吐计时包含循环与逐次计时/校验开销，分位数按单次测量；这是一次短样本，不是正式性能承诺或与 C++ 的比较。后续均匀/变长/多线程和重复样本仍须补齐。
