# P4.2 本地文件后端交付记录

状态：进行中。

已实现 local_files 执行层：打开根目录能力后，所有用户子路径通过 cap-std 的 Dir 操作。根目录是用户授权的环境路径，子路径必须相对且不含父路径分量；cap-std 负责实际文件系统解析中的根目录限制。依赖闭包与许可证见 [依赖审计](P4.2依赖审计.md)。

文件句柄表持有 Arc<File>，句柄编号不复用，迟到代次拒绝；执行偏移读写时只保留文件 Arc，不持有句柄表锁。Close 移除表项不会释放其他已取得 Arc 的 I/O。Read/Write 使用平台 FileExt 偏移调用，短传输按实际长度返回，错误始终归还缓冲。已实现 SetLen、文件/目录同步、目录创建、重命名和删除。

本地真实临时目录测试通过：偏移写入、文件同步、关闭重开、短读、目录同步；拒绝父路径逃逸、绝对路径和根外符号链接。设备根目录创建本身使用用户提供的环境路径，不能将这一授权扩大到后续子路径。

此段记录执行层最初的交付范围；工作线程与分段映射的当前状态见后文。

本轮 Rust 1.98.1 格式、Clippy、全特性测试与 rustdoc 通过，107 个运行测试、6 个文档测试。P4.2 保持进行中。

## 工作线程队列接入

ThreadPoolDeviceFactory 已启动配置数量的工作线程。pending、inflight 和 ready 合计受 queue_capacity 限制，完成未收取也占容量；队列在创建时预留空间，接受后工作线程只搬运拥有型请求和缓冲。句柄操作在本地执行层完成，线程不接收业务上下文。

关闭先停止接受、唤醒线程并排空待处理项，再按截止时间等待线程退出；超时保留 Shared 及在途缓冲。完成项仍可 poll 收取。Drop 不无限等待系统 I/O，工作线程持有 Shared，避免设备外观销毁后提前释放资源。取消可标记仍排队的目标；已经进入系统 I/O 的操作继续完成，不谎称已取消内核调用。

新增两项公开设备测试，实际运行三工作线程的八个非重叠偏移写、同步和设备重开读取，并验证 shutdown 后收取完成、完成未收取的背压，以及失败归还同一缓冲地址。

## Linux 目录同步修复

上轮 CI 34460441868 的 Linux 三组合在目录同步测试失败，错误为 Bad file descriptor；macOS 通过。cap-primitives 的 Linux 目录能力使用 O_PATH，不能直接用于 fsync。改为在同一根目录能力下以可读文件方式打开目录，检查其确为目录后 sync_all。保留原失败测试，等待新 CI 验证 Linux 修复，不用 macOS 通过替代该证据。

## 分段映射与实际代次隔离

SegmentedStorage 按二次幂段长切分逻辑范围，检查地址溢出；映射保存设备句柄和段代次。失效操作先移除当前绑定并递增代次，新绑定必须匹配该代次。物理文件名包含段号与代次，旧请求即使迟到执行也只能修改旧文件。完成处理必须再次核验句柄、段代次与偏移。代次耗尽返回错误，不回绕。此工具由后续 P4.3 日志请求路由接入。

检查点材料名限制为安全单组件，提交计划先验证文件同步、目录同步和原子重命名能力，再给出重命名与目录同步两步。调用者须提前同步新目录的父目录项、材料、manifest 和临时提交文件。生成计划不代表发布完成，也不代替 P5 的提交状态机与崩溃恢复。

新增五项 storage 测试，其中两项使用真实工作线程与临时文件：跨段边界、映射失效、命名与能力拒绝，以及新段绑定后迟到旧写不污染新文件、提交文件同步后发布与重开读取。另有公开设备竞争测试同时提交 32 个写入与取消，允许排队取消或已开始写入两种合法结果；关闭超时后继续排空，逐项检查原缓冲地址、内容、唯一完成和无额外完成。
