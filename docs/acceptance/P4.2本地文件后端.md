# P4.2 本地文件后端交付记录

状态：进行中。

已实现 local_files 执行层：打开根目录能力后，所有用户子路径通过 cap-std 的 Dir 操作。根目录是用户授权的环境路径，子路径必须相对且不含父路径分量；cap-std 负责实际文件系统解析中的根目录限制。依赖闭包与许可证见 [依赖审计](P4.2依赖审计.md)。

文件句柄表持有 Arc<File>，句柄编号不复用，迟到代次拒绝；执行偏移读写时只保留文件 Arc，不持有句柄表锁。Close 移除表项不会释放其他已取得 Arc 的 I/O。Read/Write 使用平台 FileExt 偏移调用，短传输按实际长度返回，错误始终归还缓冲。已实现 SetLen、文件/目录同步、目录创建、重命名和删除。

本地真实临时目录测试通过：偏移写入、文件同步、关闭重开、短读、目录同步；拒绝父路径逃逸、绝对路径和根外符号链接。设备根目录创建本身使用用户提供的环境路径，不能将这一授权扩大到后续子路径。

尚未接入工作线程接受队列、取消/关闭排空和分段映射，ThreadPoolDeviceFactory 仍明确未实现；本测试不代表公开文件设备已可用。下一步连接执行层与拥有型请求队列。

本轮 Rust 1.98.1 格式、Clippy、全特性测试与 rustdoc 通过，107 个运行测试、6 个文档测试。P4.2 保持进行中。
