# P4.1 设备请求协议

状态：进行中。

MemoryDevice 已接通有界接受队列和 poll 执行：Open、Read、Write、SetLen、Close 真实访问内存文件。Open 的 create_new=true 拒绝已存在路径，false 只打开已有路径。文件和句柄数量均受容量限制，数据总长度受 max_bytes 限制，I/O ID 与句柄 ID 单调且不回绕。

拒绝时归还原请求，不消耗编号。读写完成不论成功或失败均归还原 AlignedBuffer；poll 先预留输出容量再取走请求，避免分配失败后丢失终结。EOF 可返回短读，缓冲未覆盖部分保持原内容。

shutdown 停止接收并执行待处理请求，完成项继续由 poll 收取；超时保留队列和推进能力。设备排空不意味着调用者已经收取全部完成项，后续 Session 排空必须处理这一边界。内存设备不宣称文件同步、目录同步或进程重启持久化，SyncFile 返回 UnsupportedDurability。

## 故障、短传输和取消子步骤

MemoryFault 绑定到下一次成功接受的请求；队列满拒绝不消费故障。Fail 在执行前返回指定 I/O 错误并归还原缓冲；Short 只限制读写的实际传输字节数，归还的缓冲长度与身份不变。短写仅更新已传输部分，后续读取验证未写部分没有被误提交。

set_reverse 控制 pending 队列反向执行，poll 与 shutdown 使用相同顺序。它会改变操作执行次序，不只是通知次序，测试依赖必须明确设置。Cancel 在执行时标记仍待执行的目标；目标终结为 Interrupted 并归还缓冲。目标已执行或已收取时取消为幂等 Done，不再投递目标结果。取消请求本身有独立 ID 和一次终结。
